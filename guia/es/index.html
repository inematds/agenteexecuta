Qué es

Una etapa de arquitectura antes de trabajos complejos

Demasiados agentes releyendo el mismo contexto desperdician tokens; la secuencia a ciegas desperdicia tiempo. La skill decide conscientemente y solo después ejecuta.

🚪 Umbral de proporcionalidad

Primera decisión: ¿la tarea requiere dividirse, contar con varios ejecutores o manejar mucho contexto? Si no, ejecútala directamente, sin burocracia de planificación.

⚖️ Matriz de decisión

Señales puntuadas para secuencial y paralelo, con umbral objetivo: una diferencia ≥ 2 puntos decide; empate o diferencia menor → híbrido.

💸 Ejecutor más económico

Script para lo mecánico, modelo económico para lo estructurado y modelo avanzado solo para estrategia y creación. Nunca un agente esperando un render.

Cómo funciona

De la solicitud al plan: antes del primer subagente

El flujo separa el razonamiento de la ejecución: centraliza las decisiones, registra el contexto una sola vez, automatiza lo mecánico y paraleliza solo lo que es realmente independiente.

Solicitud→ Umbral de proporcionalidad→ Descomponer→ Matriz de decisión→ Plan compacto→ Ejecución→ Revisión central
1

Secuencial

Tareas dependientes o con mucho contexto compartido. Lo aprendido en una etapa alimenta la siguiente.

2

Paralelo

Tareas independientes, entradas congeladas y poco contexto por tarea. Los renders y las conversiones se convierten en scripts en paralelo.

3

Híbrido

Estándar para proyectos grandes: planificación centralizada, especificación única, ejecución independiente en paralelo y revisión central.

Requisitos previos

Lo que necesitas

La skill es un paquete de archivos Markdown: funciona en cualquier agente que admita skills. El script de prueba usa la CLI de Claude Code.

Un agente con skills

Claude Code, ChatGPT (subida del zip) o Codex. El núcleo es universal; las asignaciones por plataforma están en references/.

# verificar la CLI (para Claude Code)
claude --version

Git

Para clonar el repositorio con la skill, la guía y el script de prueba.

git clone https://github.com/inematds/agenteexecuta

Bash (opcional)

Solo para ejecutar la prueba de comportamiento baseline × con skill.

bash --version
Guía de uso · paso a paso

Instalar y usar la skill

Del clon a la validación de comportamiento, con comandos reales.

1

Clona el repositorio

La skill está en la carpeta arquiteto-de-execucao/, con SKILL.md, referencias y script de prueba.

git clone https://github.com/inematds/agenteexecuta
cd agenteexecuta
2

Instálala en Claude Code

Copia la carpeta de la skill en el directorio de skills del usuario. Se activará automáticamente antes de trabajos con subagentes o lotes.

cp -r arquiteto-de-execucao ~/.claude/skills/  # disponible en la próxima sesión
3

O instálala en ChatGPT / Codex

Usa el zip listo: incluye el agents/openai.yaml con la configuración de interfaz para el ecosistema OpenAI.

# sube este archivo al crear la skill/GPT:
arquiteto-de-execucao-v2.zip
4

Úsala en un trabajo grande

Pide una tarea con varias entregas. La skill genera el plan compacto ANTES de crear cualquier subagente: estrategia, qué es secuencial/paralelo, ejecutores, límites y riesgo principal.

# ejemplo de solicitud que activa la skill:
"Produza 15 vídeos curtos da série X usando agentes. O guia de estilo tem 40 páginas."
5

Si tienes dudas, consulta la matriz

Señales puntuadas y umbral objetivo, con ejemplos resueltos (15 videos, investigación de mercado, migración, 500 archivos).

cat arquiteto-de-execucao/references/decision-matrix.md
6

Valida el comportamiento (baseline × con skill)

El script ejecuta los 3 escenarios de prueba en modo headless y guarda las respuestas para compararlas manualmente con los criterios de references/test-scenarios.md.

./arquiteto-de-execucao/scripts/test-skill.sh              # prueba rápida: escenario 1, 1 repetición
./arquiteto-de-execucao/scripts/test-skill.sh all both 5   # batería completa
Ejemplos

El principio en cifras y el plan que produce la skill

El ahorro no viene de que «secuencial siempre sea mejor»: viene de amortizar el costo del contexto compartido.

💰 Costo del contexto repetido

# 3 agentes releyendo el mismo material:
3 × (50k contexto + 20k execução) = 210k tokens

# 1 ejecutor reutilizando el contexto:
50k + 20k + 20k + 20k = 110k tokens

📋 Plan compacto (salida de la skill)

Estratégia: híbrida.
Sequencial: planejamento, spec e revisão final.
Paralelo: tarefas independentes e mecânicas.
Executores: avançado p/ decisões; econômico
  p/ checklist; scripts p/ render.
Contexto: PROJECT-SPEC.md + CHECKLIST.md.
Limites: 3 subagentes, 2 tentativas,
  retrabalho só dos reprovados.

Evolución de la skill

De la versión monolítica a la skill ligera con validación de comportamiento.

v1
Skill originalMetodología completa en un SKILL.md extenso: buen contenido, pero cuerpo abultado, descripción demasiado amplia y sin «cuándo no usar».
v2
Versión actual — panel de controlUmbral de proporcionalidad, descripción bilingüe enfocada en el disparador, cuerpo conciso (~400 palabras), matriz con umbral objetivo, referencias por plataforma (Claude Code, ChatGPT/Codex) y script de prueba baseline × skill.
v3
Próximos pasosBatería completa de validación (5+ repeticiones por escenario), condiciones de veto en la matriz (una dependencia inestable veta el paralelismo, independientemente de la suma) y ajuste del discurso según la ganancia real medida frente a la línea de base.
